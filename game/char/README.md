# Hình nhân vật

Thả file vào thư mục này, đặt tên theo 10 mốc đời: `0` (Tay trắng) đến `9` (Tỷ phú).

- Đuôi file: `.mp4` (video lặp, ưu tiên), `.png`, `.webp` hoặc `.jpg`
- Khung ngang 4:3 (ví dụ 1080×800), nhân vật ở giữa, đầu nằm trong nửa trên
- Thiếu mốc nào thì game dùng hình của mốc thấp hơn gần nhất
- Không có file nào thì game vẽ nhân vật tạm bằng SVG
